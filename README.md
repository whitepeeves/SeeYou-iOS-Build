# SeeYou - iOS Build

Este repositorio contiene **solo el cliente** (web + Capacitor) de SeeYou

El backend, la logica de negocio y los secretos de produccion NO se encuentran aquí ni ligados a esta cuenta. 

## Que hay aqui
- `src/` - cliente web (HTML/CSS/JS) que se empaqueta con Capacitor
- `android/`, `ios/` - proyectos nativos generados por Capacitor
- `capacitor.config.json`, `package.json` - configuracion minima de Capacitor
